Questions, answered plainly.

Do I have to rewrite my application?

No. Your SDK or HTTP client only needs a configurable base URL. Point it at EQUAL while recording or replaying, then point it back at the real provider when you are done.

Do I still need API keys after recording?

Not for ordinary replay. EQUAL redacts common credential fields before storing the cassette and can match later requests after redaction. Review every file yourself: no automatic redactor can recognize every secret in every format.

Is the generated OpenAPI a complete description of the provider?

No. It is a valid OpenAPI 3.1 document built from observed traffic. Unrecorded endpoints and fields are absent. It is a useful draft and test artifact, not an authoritative provider contract.

Does it work with WebSockets, SSE, or any network protocol?

Version 0.2.0 handles ordinary buffered HTTP request-response traffic. WebSocket sessions, SSE streams, and non-HTTP protocols are outside the current boundary.

Can I deploy it as a production gateway?

No. EQUAL is deliberately a development and testing tool. It does not provide production authentication, tenant isolation, streaming, or rate limiting.
